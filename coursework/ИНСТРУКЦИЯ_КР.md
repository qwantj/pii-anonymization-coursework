# Инструкция по запуску и проверке курсовой работы

## 1. Требования к проекту (Вариант № 8 — чётный)

Программа выполняет распознавание и синонимическое обезличивание **10 атрибутов персональных данных (ПДн)** чётного варианта:

1. Фамилия (`SURNAME`)
2. Имя (`NAME`)
3. ИНН 10 и 12 знаков (`INN`, с проверкой контрольных разрядов ФНС)
4. Номер паспорта РФ (`PASSPORT`)
5. Номер банковской карты (`BANK_CARD`, с проверкой контрольной суммы Луна)
6. Номер ОГРНИП (`OGRNIP`, с проверкой остатка `mod 13`)
7. IP-адрес IPv4 (`IP_ADDRESS`)
8. E-mail (`EMAIL`)
9. Номер свидетельства о рождении (`BIRTH_CERTIFICATE`)
10. Код КЛАДР (`KLADR`)

### Этапы сдачи и нормативы:
- **КМ-2 (распознавание ПДн):** тестовый корпус $\ge 100$ текстов и $\ge 50$ экземпляров каждого атрибута; оценка как `Token Classification` по схеме `BIO` (строго один атрибут на токен/слово, иначе `O`); `Weighted F1 >= 0.85`, `Macro F1 >= 0.80`; обязательная проверка контрольных разрядов.
- **КМ-3 (обезличивание и семантика):** синонимическая замена с сохранением рода, числа и падежа (`pymorphy3`), сохранение косвенных признаков и контрольных разрядов, свойство идемпотентности (`IdempotencyVault`), случайность при повторном запуске (`SystemRandom`), разрешение минимум одной практической проблемы обезличивания (решены: двуполые имена `Саша`/`Женя`/`Валя`, двойные дефисные фамилии `Петров-Водкин`, морфологическая омонимия `Иванова`/`Анне`), интерфейс `anon(text) -> (anonymized_text, spans)`, оценка сохранения смысла через `BERTScore` в сравнении с маскированием (`*`) и выводы.

## 2. Основные файлы проекта

- [`coursework/run_coursework.py`](run_coursework.py) — главная точка входа (оценка F1, обезличивание, BERTScore, генерация графиков и отчёта).
- [`coursework/data/data_generator.py`](data/data_generator.py) — генератор бенчмарка (`factRuEval-2016` + 10 атрибутов чётного варианта).
- [`coursework/data/dataset.json`](data/dataset.json) — тестовый бенчмарк (246 текстов, 1189 сущностей).
- [`coursework/src/core_pipeline.py`](src/core_pipeline.py) — сквозной пайплайн `CourseworkPipeline` и функция `anon()`.
- [`coursework/src/idempotency_manager.py`](src/idempotency_manager.py) — потокобезопасное хранилище идемпотентности `IdempotencyVault`.
- [`coursework/src/advanced_morphology.py`](src/advanced_morphology.py) — контекстное снятие омонимии рода для двуродовых имён.
- [`coursework/evaluation/f1_evaluator.py`](evaluation/f1_evaluator.py) — расчёт метрик Token Classification (BIO).
- [`coursework/evaluation/bert_score_evaluator.py`](evaluation/bert_score_evaluator.py) — расчёт BERTScore (`bert-base-multilingual-cased`, IDF).
- [`build_all_coursework_reports.py`](../build_all_coursework_reports.py) — генератор академических отчётов КМ-1, КМ-2 и КМ-3 в `docs/` по ГОСТ 7.32-2017.

## 3. Установка зависимостей

Все команды выполняются из корневой директории репозитория:

```bash
git clone https://github.com/qwantj/pii-anonymization-coursework.git
cd pii-anonymization-coursework
python -m pip install -r requirements.txt
```

При необходимости можно также установить зависимости из каталога `coursework/`:

```bash
python -m pip install -r coursework/requirements.txt
```

```bash
python coursework/data/data_generator.py
```

Проверка объёма выборки и количества экземпляров по всем 10 атрибутам:

```bash
python -c "import json, collections; d=json.load(open('coursework/data/dataset.json', encoding='utf-8')); c=collections.Counter(e[0] for x in d for e in x['entities']); print('texts=', len(d)); print(dict(sorted(c.items()))); print('min=', min(c.values()))"
```

Ожидаемый результат: `texts= 246` ($\ge 100$), `min= 60` ($\ge 50$ по каждому из 10 классов).

## 5. Команды запуска

### 5.1. Полный цикл оценки и построения отчёта

```bash
python coursework/run_coursework.py
```

Выполняет:
1. загрузку бенчмарка `coursework/data/dataset.json`;
2. оценку качества распознавания (`Weighted F1`, `Macro F1`, `Precision`, `Recall` в разрезе всех 10 атрибутов);
3. синонимическое обезличивание (с `IdempotencyVault`) и символьное маскирование (`*`);
4. расчёт `BERTScore` (исходный vs синонимизированный, исходный vs замаскированный);
5. сохранение метрик в `coursework/report/evaluation_artifacts.json`, построение графиков и генерацию `coursework/report/report.docx` и `coursework/report/report.md`.

### 5.2. Специализированные проверки требований КР

```bash
python coursework/run_coursework.py --tests
```

Проверяет на контрольных примерах:
- идемпотентность и согласование падежей (*«Иванов … Иванова … Иванову … Ивановым»*);
- разрешение омонимии рода и изоляцию клауз (*«Саша оплатила …»*, *«Саша оплатил …»*, *«Саша пришла в офис, а Женя ушёл домой.»*);
- обработку двойных дефисных фамилий (*«Петров-Водкин Иван»*) и омонимичных фамилий (*«Иванова Анна»*).

### 5.3. Интерактивная демонстрация

```bash
python coursework/run_coursework.py --demo
```

Пример текста для проверки (содержит валидные по алгоритму Луна и ФНС реквизиты):

```text
Иванов Иван (паспорт 4510 123456, ИНН 7707083893) отправил письмо на ivan@example.ru и оплатил картой 4276 3800 1234 5679.
```

Программа выведет:
- найденные спаны ПДн в формате ЛР1 (`[[tag, start, end], ...]`);
- синонимически обезличенный текст;
- замаскированный текст.

Для выхода введите `exit`.

### 5.4. Генерация академических отчётов КМ-1, КМ-2 и КМ-3 по ГОСТ 7.32-2017

```bash
python build_all_coursework_reports.py
```

Сформирует в каталоге `docs/` файлы `.docx` и `.md` для КМ-1, КМ-2 и итоговой пояснительной записки КМ-3 с актуальными метриками из `coursework/report/evaluation_artifacts.json`.

### 5.5. Запуск всех автотестов

```bash
pytest
```

### 5.6. Опциональный запуск с нейросетью RoSBERTa INT8 ONNX

Лёгкий классификатор `logreg` (`coursework/models/ner_token_classifier.joblib`) включён в репозиторий и работает сразу. Для запуска с квантованной нейросетью `RoSBERTa INT8 ONNX` (~405 МБ):

```bash
python scripts/download_models.py
python coursework/run_coursework.py --detector onnx --onnx
```
