# Инструкция по выполнению курсовой работы

## 1. Что требует задание

Курсовая должна распознавать и синонимически обезличивать:

- нечётные и чётные номера в журнале;
- фамилию и имя;
- ИНН;
- паспорт;
- банковскую карту;
- СНИЛС;
- ОГРНИП;
- URL;
- IP-адрес;
- телефон;
- E-mail;
- свидетельство о браке;
- свидетельство о рождении;
- кадастровый номер;
- код КЛАДР.

Также нужны:

- минимум 100 текстов;
- минимум 50 экземпляров каждого класса;
- BIO/token-classification оценка;
- Weighted F1 не ниже 0.85;
- Macro F1 не ниже 0.80;
- проверка контрольных разрядов;
- синонимическая замена;
- случайность повторных запусков;
- идемпотентность одинаковых сущностей;
- сохранение рода, числа и падежа;
- сравнение с маскированием по BERTScore.

## 2. Нужно ли обучать модель

**Обязательного обучения нейросети в КР нет.** В задании разрешены:

- регулярные выражения;
- алгоритмические правила;
- нейросеть;
- гибридный подход.

В проекте используется гибрид:

- структурированные атрибуты — регулярные выражения и валидаторы;
- фамилии и имена — NER/морфологические правила;
- обезличивание — `pymorphy3`, случайные генераторы и кэш идемпотентности.

Поэтому для КР не нужно запускать Google Colab или fine-tuning RuBERT.
Но если преподаватель попросит AI-модель, можно отдельно использовать модель,
обученную для ЛР1. Она не заменяет правила для структурированных атрибутов.

вывод.

python -c "import json,collections; d=json.load(open(r'C:\Dev\CTZI\coursework\data\dataset.json',encoding='utf-8')); c=collections.Counter(e[0] for x in d for e in x['entities']); print('texts=',len(d)); print(dict(sorted(c.items()))); print('min=',min(c.values()))"

## 6. Полный запуск

```powershell
python C:\Dev\CTZI\coursework\run_coursework.py
```

Запуск выполняет:

1. загрузку бенчмарка;
2. token-classification оценку;
3. синонимическое обезличивание;
4. маскирование;
5. сравнение двух методов по BERTScore;
6. построение графиков;
7. генерацию `report/report.docx`.

Порог распознавания:

```text
Weighted F1 >= 0.85
Macro F1 >= 0.80
```

## 7. Специализированные проверки

```powershell
python C:\Dev\CTZI\coursework\run_coursework.py --demo
```

Пример текста:

```text
Иванов Иван отправил письмо на ivan@example.ru и оплатил картой 4276 3800 1234 5678.
```

Программа должна вывести:

- найденные спаны в формате ЛР1;
- синонимически обезличенный текст;
- замаскированный текст.

Для выхода введите `exit`.

## 10. Формулировка для защиты

> В работе реализован гибридный pipeline. Структурированные атрибуты
> распознаются регулярными выражениями и проверяются валидаторами контрольных
> разрядов. Текстовые атрибуты обрабатываются морфологическим анализом.
> Синонимическое обезличивание сохраняет грамматический род, число и падеж,
> а также косвенные структурные признаки. Для одинаковых сущностей используется
> единое значение в `IdempotencyVault`. Качество распознавания оценивается
> token classification по BIO, а сохранение смысла сравнивается с маскированием
> по BERTScore.
