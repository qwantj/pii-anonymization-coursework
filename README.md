# Программный комплекс распознавания и синонимического обезличивания персональных данных (ПДн)

Курсовая работа по дисциплине **«Цифровые технологии защиты информации»** (НИУ «МЭИ», вариант № 8 — чётный).

Комплекс решает задачу автоматического обнаружения 10 категорий ПДн по схеме **Token Classification (BIO)** и их последующего **синонимического обезличивания** с сохранением грамматических категорий (род, число, падеж), косвенных признаков, валидности контрольных разрядов, идемпотентности и семантического смысла текста (оценка через **BERTScore**).

---

## 1. Поддерживаемые атрибуты ПДн (чётный вариант)

| № | Атрибут | Тег BIO | Метод распознавания и верификации |
|---|---|---|---|
| 1 | Фамилия | `SURNAME` | ML/NER (`logreg` / `RoSBERTa`) + морфология `pymorphy3` + склейка дефисных фамилий |
| 2 | Имя | `NAME` | ML/NER (`logreg` / `RoSBERTa`) + контекстное снятие омонимии рода |
| 3 | ИНН (10 и 12 знаков) | `INN` | RegEx + проверка контрольных разрядов ФНС (`mod 11`) |
| 4 | Паспорт РФ | `PASSPORT` | RegEx + проверка диапазона кода региона и года выдачи |
| 5 | Банковская карта | `BANK_CARD` | RegEx (13–19 цифр) + алгоритм Луна (`mod 10`) |
| 6 | ОГРНИП (15 знаков) | `OGRNIP` | RegEx + проверка контрольной цифры (`mod 13`) |
| 7 | IP-адрес (IPv4) | `IP_ADDRESS` | RegEx с проверкой диапазона октетов `[0..255]` |
| 8 | E-mail | `EMAIL` | RegEx (RFC 5322 + Punycode) |
| 9 | Свидетельство о рождении | `BIRTH_CERTIFICATE` | RegEx римских цифр серии, буквенного кода и 6-значного номера + контекстный арбитраж ЗАГС |
| 10 | Код КЛАДР | `KLADR` | RegEx структуры кодов субъектов РФ (11–17 цифр) + контекстный фильтр |

Каждый токен текста относится строго к одному атрибуту ПДн или тегу `O` (разрешение коллизий спанов по строгой иерархии приоритетов).

## 2. Набор данных и метрики качества

Тестовый бенчмарк [`coursework/data/dataset.json`](coursework/data/dataset.json) включает **246 связных русскоязычных текстов** (**1189 целевых сущностей**, не менее 60 экземпляров каждого из 10 атрибутов при норме $\ge 50$):
- **45 реальных новостных предложений** с разнообразными падежами ФИО из отложенной тестовой части корпуса `factRuEval-2016` (`testset`);
- тексты с повторными упоминаниями одного субъекта в разных падежах (проверка идемпотентности);
- тексты с двуполыми именами (`Саша`, `Женя`, `Валя`) и двойными дефисными фамилиями (`Петров-Водкин`, `Мамин-Сибиряк`, `Салтыков-Щедрин` и др.);
- связные документы с финансовыми и регистрационными реквизитами.

## 3. Алгоритмы обезличивания, идемпотентность и BERTScore

- **Сохранение структуры и контрольных разрядов:** в ИНН сохраняются первые 4 цифры кода налогового органа с пересчётом разрядов ФНС; в банковской карте сохраняются 6-значный BIN и последние 4 цифры с подгонкой 12-го разряда под алгоритм Луна; в ОГРНИП сохраняются первые 5 цифр и пересчитывается остаток `mod 13`; в паспорте сохраняется серия; в e-mail — доменная зона; случайность обеспечивается через `random.SystemRandom`.
- **Идемпотентность и морфология (`IdempotencyVault` + `pymorphy3`):** канонические замены сохраняются в именительном падеже и при повторном упоминании субъекта склоняются в нужный падеж контекста (*«Иванов … Иванова … Иванову … Ивановым»* $\rightarrow$ *«Губанов … Губанова … Губанову … Губановым»*).
- **Решённые проблемы обезличивания:**
  1. **Двуполые имена (`Саша`, `Женя`, `Валя`):** изоляция синтаксической клаузы (предложения и запятые перед союзами) с анализом глаголов прошедшего времени, причастий, отчеств и местоимений в порядке близости к имени (*«Саша пришла в офис, а Женя ушёл домой»* $\rightarrow$ женское и мужское имена); при разных лицах с одним унисекс-именем в документе кэш разделяется по роду, а при нейтральном повторном упоминании (*«Документы Саши готовы»*) сохраняется идемпотентность.
  2. **Двойные дефисные фамилии (`Петров-Водкин`, `Мамин-Сибиряк`):** пост-обработчик склеивает части фамилии в единый спан `SURNAME`, а `IdempotencyVault` генерирует пару несовпадающих фамилий нужного рода и склоняет обе части через `inflect_hyphenated_entity`.
  3. **Морфологическая омонимия (`Иванова`, `Жени/Жене`):** контекстный морфоразбор `get_morph_info_for_tag` учитывает тег сущности и определённый род, различая женский именительный падеж (*«Иванова Анна оплатила»*) и мужской родительный падеж (*«документы Иванова Максима»*).

### Оценка сохранения смысла (BERTScore, модель `bert-base-multilingual-cased`, IDF)

| Метод обезличивания | Precision | Recall | F1 | Преимущество |
|---|---|---|---|---|
| **Синонимическая замена** | **0.8852** | **0.8898** | **0.8874** | **+0.2009 (+29.3%)** |
| **Маскирование (`*`)** | 0.6806 | 0.6931 | 0.6865 | Базовый уровень |
| **Изолированные сущности (ФИО)** | — | — | **0.5424** vs 0.2433 | **+0.2991** |

## 4. Установка и запуск

```bash
git clone https://github.com/qwantj/pii-anonymization-coursework.git
cd pii-anonymization-coursework
pip install -r requirements.txt
```

### Основные команды

```bash
# 1. Полный цикл: оценка F1, обезличивание, расчёт BERTScore, генерация графиков и отчёта
python coursework/run_coursework.py

# 2. Специализированные проверки (идемпотентность, двуполые имена, двойные фамилии, омонимия)
python coursework/run_coursework.py --tests

# 3. Интерактивный демонстрационный режим
python coursework/run_coursework.py --demo

# 4. Запуск всех автотестов
pytest
```

### Опциональный запуск с нейросетью RoSBERTa INT8 ONNX

Тяжёлые веса трансформера не хранятся в git-репозитории. Чтобы использовать режим `RoSBERTa INT8 ONNX` (~405 МБ):

```bash
python scripts/download_models.py
python coursework/run_coursework.py --detector onnx --onnx
```
